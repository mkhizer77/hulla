# @hulla/test-vectors

The executable specification: JSON vectors every engine must pass (ADR-0003), the schema they follow, the TypeScript runner and the traceability matrix that maps every GDD rule and edge ID to vectors and tests.

## Layout
- `schema/vector.schema.json`: draft-07 schema for a vector; the runner validates every file against it.
- `thulla/V-*.json`: the vectors. Generated by `tools/vector-gen` from authored scenarios and from exhaustive enumeration of small two-player endgames; never edited by hand. Each carries the rules `version` it was generated against and the final `stateHash`, so a rule change that alters an outcome or a hash shows up as a failing vector until the vectors are regenerated on purpose.
- `thulla/rule-ids.json`: every R-id and E-id with its scope (`engine`, `table-core`, `client`, `later`).
- `thulla/traceability.md`: generated by `scripts/traceability.ts`; 100% of engine-scope IDs must have at least one vector and one test or the script exits 1 and CI fails.
- `runner-ts/`: `runVector` applies a vector to `@hulla/rules-engine` and returns the failures; the test in `__tests__` runs every file.

## A vector
Either a `deal` (seed, seat count, dealer, so the shuffle and the commitment are checked) or a `setup` (a full explicit state: every hand, the discard, the leader, the open trick). Then `moves`, each with the seat, the move, an optional `draw` index that stands in for the random draw, and the expected outcome. Then `assert`, a fixed vocabulary: `phase`, `leaderSeat`, `turnSeat`, `trickIndex`, `hands`, `handContains`, `handCounts`, `escapeOrder`, `bhabhiSeat`, `confirmedBhabhi`, `discard`, `discardCount`, `pendingAutoLead`, `lastEvents`, `eventsInclude`, `stats`, `forcedBhabhi`, `autoPlay`, `results`, `views`, `commitment`, `leaderHoldsAceOfSpades`, `stateHash`.

## Commands
```
pnpm vectors                              # from the root: runs the vectors and the traceability check in every engine
pnpm --filter @hulla/test-vectors traceability   # regenerate thulla/traceability.md
pnpm --filter @hulla/vector-gen generate         # regenerate the vectors (tools/vector-gen)
```

## Boundaries
Depends on the engines and shared-ts. The C# runner joins when the mirror is built (ADR-0019); the format carries nothing TypeScript-specific.
