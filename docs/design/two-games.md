# Two games, one app

Decided by the owner on 16 November 2026. Thulla and Rung get equal weight everywhere. The player picks a game on Home; friends, coins, level, cosmetics, the pass and the daily reward stay shared.

## What is shared and what is per game

| Shared | Per game |
|---|---|
| Account, name, avatar, level, XP, coins | How to start: seats and Casual or Ranked for Thulla, the rule set for Rung |
| Friends, invites, room codes, voice, chat, emotes | The lobby's seat layout and its rules line |
| Shop and everything owned | The table and the result screen |
| Season pass, daily reward, push | Stats, achievements, leaderboards (each also has an All view) |
| The room: it can switch game without leaving voice | Rulebook and tutorial |

## Screens

- **Home**: two game cards of the same size, stacked. A card opens that game's page. Join by Code and the daily reward stay; seat size, Casual or Ranked, Play now and Create Room move into the game pages. A friend's room in the banner names its game. Home has no yellow button.
- **Game page**: back, the game's title, the book for its rulebook. Thulla: seat size, Casual or Ranked, Play now, Create Room. Rung: the three rule sets, Play now (Quick Play), Create Room. A line with the player's own numbers for that game.
- **Lobby**: the title names the game. Code, share, voice, chat, Ready and Start are the same. Thulla shows its ring of three to six seats. Rung shows four seats as two pairs with the partner opposite; an empty seat offers Invite and Bot; the host can swap two seats to choose the pairs. The host switches game with one button.
- **Trophies**: an All, Thulla, Rung filter under the Missions, Achievements, Leaderboard segment; it remembers the last choice. Each game has its own boards and achievements. The daily and weekly mission draw mixes both games and each row shows its game.
- **Profile**: the stats card has a Thulla and a Rung side. Level, coins and titles stay shared.
- **Shop**: nothing is sold per game. The preview can show either table. The pass earns from both.
- **Friends**: a friend's status names the game, and an invite says which game it is to.
- **Results**: Thulla's stays. Rung shows a short strip after each deal that moves on by itself, and the full team result when the bazi ends.

## Rung Quick Play

A solo player or a pair searches for a table of four. Two who queued together sit opposite as partners. If nobody is found in 15 seconds the client asks for a table with bots; a matched player who never arrives is replaced by a bot. Quick Play is the Rung rule set to five points. Ranked stays Thulla only.

## What a Rung deal pays (OQ-056, interim)

A deal is about half a Thulla round, so it pays about half of one.

| | XP | Coins |
|---|---|---|
| Deal won / lost | 12 / 6 | 18 / 9 |
| Court, for the pair that scored it (double for a 52-court) | +10 | +15 |
| Bazi won / lost, on its last deal | +30 / +10 | +40 / +10 |

The friend bonus, the login streak and the daily soft cap apply as in Thulla.
