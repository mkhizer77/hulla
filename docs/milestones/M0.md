# M0: tooling, Thulla engines, shared vectors

Goal: the rulebook becomes executable in both languages before any UI or server code exists. Duration guide: two weeks. Reference: GDD §6 (rules R1–R53, edge cases E1–E28, toggles §6.13, pseudocode §6.14, worked examples §6.16, vector format Appendix C), ARCHITECTURE §5, §7 and §13, PROJECT_STRUCTURE §1 and §4, CODING_RULES §3, §4, §9.

## Deliverables
1. Workspace tooling: `package.json`, `pnpm-workspace.yaml`, `tsconfig.base.json`, ESLint flat config (typescript-eslint strict), Prettier, dependency-cruiser rules from ARCHITECTURE §5, Vitest and fast-check. Root scripts exactly as CONTRIBUTING.md lists them.
2. `packages/shared-ts`: `Result`, the error-code catalogue, ids, a xoshiro128** PRNG, a SHA-256 helper, with tests.
3. `packages/rules-engine`: the Thulla `GameModule` (ARCHITECTURE §7.1), pure and deterministic, every rule and edge case implemented, all §6.13 toggles including two decks and 3–8 seats, the two-player endgame (R37–R42) and the forced-outcome search for 12 or fewer cards.
4. `packages/rules-engine-cs`: netstandard2.1 mirror with no UnityEngine, `System.Random` or `DateTime.Now`; a UPM `package.json`; NUnit tests under `dotnet test`.
5. `packages/test-vectors`: at least 150 vectors covering every rule and edge id, including exhaustive small two-player endgames; runners for both engines; a generated `traceability.md`.
6. `tools/equivalence`: identical seeds and random legal moves through both engines, hashes compared; property checks for card conservation, legal-only moves, termination and redaction.
7. `.github/workflows/ci.yml` wired to the real scripts and green; a README per package; `docs/STATUS.md` updated; ambiguities logged in `docs/OPEN_QUESTIONS.md`.

## Acceptance
`pnpm lint`, `pnpm test`, `pnpm vectors`, `dotnet test packages/rules-engine-cs` and `pnpm equivalence -- --rounds 10000` pass locally and in CI; the traceability matrix shows 100% of ids covered; no generated file was edited by hand; no hard-coded strings; commits follow CODING_RULES §2.3.

## Out of scope
Server, Unity project, protocol codegen (M1), content files, bots.
