# M0: tooling, Thulla engine, shared vectors

Goal: the rulebook becomes executable before any UI or server code exists. The C# mirror and the equivalence harness are deferred (ADR-0019). Duration guide: two weeks. Reference: GDD §6 (rules R1–R53, edge cases E1–E28, toggles §6.13, pseudocode §6.14, worked examples §6.16, vector format Appendix C), ARCHITECTURE §5, §7 and §13, PROJECT_STRUCTURE §1 and §4, CODING_RULES §3, §4, §9.

## Deliverables
1. Workspace tooling: `package.json`, `pnpm-workspace.yaml`, `tsconfig.base.json`, ESLint flat config (typescript-eslint strict), Prettier, dependency-cruiser rules from ARCHITECTURE §5, Vitest and fast-check. Root scripts exactly as CONTRIBUTING.md lists them.
2. `packages/shared-ts`: `Result`, the error-code catalogue, ids, the xoshiro128** PRNG, canonical JSON and a SHA-256 helper exactly as the parity rules in ARCHITECTURE §7.5 specify, with tests.
3. `packages/rules-engine`: the Thulla `GameModule` (ARCHITECTURE §7.1), pure and deterministic, every rule and edge case implemented, all §6.13 toggles for one deck and 3–6 seats (`deckCount` is a reserved field that accepts only 1; two decks and 7–8 seats are v1.2), the two-player endgame (R37–R42) and the forced-outcome search for 12 or fewer cards.
4. Deferred: `packages/rules-engine-cs` (ADR-0019).
5. `packages/test-vectors`: at least 150 vectors covering every rule and edge id, including exhaustive small two-player endgames; every vector a full explicit state validated against `schema/vector.schema.json`; a runner for the TypeScript engine, with the format kept engine-neutral for the later C# runner; a generated `traceability.md`.
6. Property checks in the TypeScript suite for card conservation, legal-only moves, termination, determinism and redaction. Deferred: `tools/equivalence` (ADR-0019).
7. `.github/workflows/ci.yml` and `nightly.yml` wired to the real scripts and green; a README per package; `docs/STATUS.md` updated; ambiguities logged in `docs/OPEN_QUESTIONS.md`. The interim choices already recorded as OQ-001 to OQ-004 are implemented as written there until the owner decides.

## Acceptance
`pnpm lint`, `pnpm test` and `pnpm vectors` pass locally and in CI; the traceability matrix shows 100% of ids covered; no generated file was edited by hand; no hard-coded strings; commits follow CODING_RULES §2.3.

## Out of scope
Server, Unity project, protocol codegen (M1), content files, bots, the C# mirror and the equivalence harness (ADR-0019), two decks and 7–8 seats (v1.2).
