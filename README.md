# Hulla

The games South Asian friends play when they are in the same room, rebuilt so the same group gets the same evening from anywhere. Thulla (Bhabhi) first, then Rung, Ludo, Tambola, Antakshari and the rest of the catalogue. Unity on Android and iOS, a web client later, one authoritative server.

**Status:** pre-production. Implementation starts with the rules engines and shared test vectors.

Contributors start at `CONTRIBUTING.md`.
